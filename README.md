# Hi, I'm Christian

I'm a software engineer in Italy. I build web products and real-time 3D, and my work is on [chri.dev](https://chri.dev).

Right now I'm at [Clover Next](https://cloverorthopedics.com/en/home-en/), building a cloud-based clinical platform for musculoskeletal care.
Before that I spent six years at [WE WEAR](https://wewear.tech/en) on 3D configurators and size technology for digital fashion.

## Selected projects

**[WE3D Configurator](https://chri.dev/projects/3d-configurator).** A no-code platform for building and publishing interactive 3D
experiences. Teams set up materials, variants and decals in a Three.js editor and publish without waiting on an engineer.

**[SizeFlow Widget](https://chri.dev/projects/size-flow).** Suggests a size from the shopper's height, weight and age, right on the
product page. It's a Web Component built with Lit, so it installs on any store whatever platform it runs on.

**[Modesto Bertotto](https://chri.dev/projects/modesto-bertotto).** A wedding suit configurator. Unreal Engine renders the fabric
on a server and pixel-streams it to a Next.js frontend.

**[HRX](https://chri.dev/projects/hrx).** A made-to-order race suit configurator with sponsors, flags and lettering, priced as you
place them. I built the Unreal Engine side and the WebSocket API that carries each choice into the scene.
