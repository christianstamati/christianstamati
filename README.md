# Hi, I'm Christian 👋

I'm a Software Engineer and Creative Technologist, working where the modern web stack meets real-time 3D.

Currently at Clover Orthopedics, building a cloud-based clinical platform for musculoskeletal care.
Before that, I spent five years at WeWear on 3D configurators and size technology for digital fashion.

I care about software that feels good to use *and* good to build on.
A polished UI means little if the codebase behind it is miserable to live in.

Outside of that, you'll usually find me at the gym.

## Selected projects

**[WE3D Configurator](https://wewear.tech/en/3d-configurator)** — Real-time 3D product customisation
embedded into e-commerce product pages. Fabrics, colours and finishes update live on the model.

**[SizeFlow Widget](https://wewear.tech/en/sizeflow)** — A drop-in widget that recommends the right
size before add-to-cart, integrating into any storefront without backend work.

**[Modesto Bertotto](https://www.modestobertotto.com/en/pages/configuratore-3d)** — The configurator
running in production on a client storefront: a web-native 3D experience built to stay fast and
accessible.
